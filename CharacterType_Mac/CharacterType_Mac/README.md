# CharacterType for macOS (초경량 네이티브 버전)

Bongo Cat 스타일의 데스크톱 상주형 키보드/마우스 반응 캐릭터 위젯입니다.  
macOS 네이티브(Swift / AppKit / CoreGraphics)로 제작되어 **메모리를 15~25MB만 사용하며, 조작하지 않을 때는 CPU 점유율이 0.0%**입니다.

---

## 🌟 주요 기능 및 특징

1. **6파트 완벽 레이어 렌더링**
   - 몸체(`body`), 왼손 준비(`leftArmReady`), 왼손 타건(`leftArmType`), 오른손 준비(`rightArmReady`), 오른손 타건(`rightArmType`), 마우스+오른팔(`mouseWithArm`)
   - 마우스와 팔이 몸체 뒤쪽(레이어 1)으로 들어가 자연스럽게 책상과 몸체 아래에서 마우스를 잡는 원근감 구현
2. **스마트 자동 모드 전환**
   - **양손 키보드 모드**: 키보드 입력 시 왼손/오른손이 책상 위에서 타건 동작
   - **마우스 모드**: 마우스를 움직이거나 클릭하면 즉시 오른손이 마우스를 잡고 커서 위치를 부드럽게 추적(Lerp 스무딩)
   - **자동 복귀**: 마우스 사용을 멈추면 설정된 시간(기본 2.0초) 후 자동으로 양손 키보드 모드로 복귀
3. **자연스러운 타건감 & 길게 누르기(Hold) 지원**
   - 키를 길게 누르고 있을 때 빠르게 덜덜 떨리는 현상(Auto-repeat flutter) 없이 키를 꾹 누르고 있는 상태 유지
   - 연타 시 35ms 찰나의 순간 손을 들었다 내려치는 리트리거(Re-trigger) 탄력 구현
4. **우클릭 편리한 메뉴 설정**
   - 크기 배율(50% ~ 300%)
   - 투명도(20% ~ 100%)
   - 마우스 흔들림 반경 조절 (얌전하게 6x4, 보통 10x6, 자유롭게 16x10)
   - 키보드 복귀 대기 시간 조절 (1.0초 ~ 4.0초)
   - 항상 위에 유지 토글 & 위치 초기화

## 🚀 빠른 시작 (최초 1회 설정)

1. 이 폴더 안에 있는 **`setup.command`** 파일을 **더블 클릭**합니다.
2. 약 1초 만에 같은 폴더에 **`CharacterType.app`**이 자동으로 생성되며 앱이 실행됩니다.
3. **이후부터는 그냥 생성된 `CharacterType.app`을 평범한 맥 앱처럼 더블 클릭해서 바로 실행하시면 됩니다.**

> [!TIP]
> 만약 `setup.command` 더블 클릭 시 "확인되지 않은 개발자" 경고가 뜨면:  
> 마우스 **우클릭(또는 Control + 클릭)** → **[열기]**를 선택해 주세요.  
> 또는 터미널에서 다음 명령어로 직접 실행할 수도 있습니다:
> ```bash
> chmod +x setup.command && ./setup.command
> ```

## ⚙️ 최초 1회 필수 권한 설정 (손쉬운 사용)

맥에서는 보안 정책상 다른 앱(사파리, 슬랙, 카카오톡 등)에서 타이핑하는 키를 감지하려면 **손쉬운 사용 권한**이 필요합니다.

1. 앱을 처음 실행하면 화면에 **'손쉬운 사용 권한' 요청 팝업**이 뜹니다.
2. **[시스템 설정 열기]**를 누릅니다.  
   *(직접 들어갈 경우: `시스템 설정` → `개인정보 보호 및 보안` → `손쉬운 사용`)*
3. 목록에서 **CharacterType**의 토글 스위치를 **'켬(허용)'**으로 바꿔주시면 즉시 키보드 타이핑 및 마우스 조작에 반응하기 시작합니다.

## 🎮 사용 방법 및 메뉴

- **위치 이동**: 캐릭터를 마우스 좌클릭한 상태로 드래그하여 원하는 위치로 옮깁니다.
- **우클릭 메뉴**: 캐릭터 위에서 마우스 우클릭을 누르면 설정 메뉴가 팝업됩니다.
  - **크기 배율**: 50%, 75%, 100%(기본), 125%, 150%, 200%, 300%
  - **투명도**: 100% ~ 20%
  - **마우스 흔들림 반경**: 캐릭터가 마우스를 움직이는 가동 범위를 실시간 변경
  - **키보드 복귀 대기 시간**: 마우스 모드에서 양손 키보드로 돌아오는 시간 (기본 2.0초)
  - **항상 위에 유지**: 켜기/끄기 토글
  - **위치 초기화**: 화면 우하단 기본 위치로 즉시 이동
  - **종료 (Quit)**: 앱 종료
